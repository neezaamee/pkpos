# Database Rules

## Multi-Tenancy
- Every table except `tenants` has a `tenant_id` UUID column with a foreign key.
- Every Eloquent model uses the `BelongsToTenant` trait.
- The trait adds a global scope: `where('tenant_id', auth()->user()->tenant_id)`.
- Admin/console operations must use `withoutGlobalScope(TenantScope::class)` explicitly.

## UUIDs
- `sales.id` and `stock_movements.id` are UUIDs generated by the **client**, not the database.
- Use Laravel's `HasUuids` trait for other tables where UUIDs are appropriate (users, products).
- Never use auto-increment integers for anything that syncs across devices.

## Money
- Column type: `bigInteger`.
- Column name: `amount_minor` (or `price_minor`, `tax_minor`).
- A separate `currency` column (default `'PKR'`).

## Migrations
- Never drop or rename a column in a single deployment. Use expand-and-contract.
- Add indexes explicitly on foreign keys and on `tenant_id` + frequently queried columns.
